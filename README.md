# Employee / Customer Data Analysis

## Project Description
This project analyses employee and customer data using Python.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Files
- week1-day5-2half2.ipynb
- reports/project_summary.txt
- reports/figures/

## Requirements
Install the required libraries:
```bash
pip install pandas matplotlib jupyter nbconvert
```
# How to Run
1. Open the project folder in VS Code.
2. Open Jupyter Notebook.
3. Run the notebook cells one by one.
4. View the generated charts in reports/figures/.
5. Open the HTML report in a browser.

## Output
The project generates data analysis results, visualisations and an HTML report.
